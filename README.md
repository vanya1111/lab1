# ЛР №1 — Апроксимація функцій: Лагранж та МНК (варіант 10)

Запуск: відкрити `index.html` у браузері. Тести: `node tests/run_tests.js`.

- 5 / 10 / 20 точок, перемикач наборів; 6 графіків (кнопка «Сітка 6 графіків»)
- Лагранж + МНК (QR Хаусхолдера, m = 1…4), діаграма залишків
- Автомасштабування осей X/Y за min/max, анімації інтерполяції та МНК, підказки при наведенні
- `js/` — код, `tests/` — тести, `docs/` — звіт, діаграми, AI Interaction Log

Примітка: у файлі варіантів для №10 набір «10 точок» містить 8 пар.
